# ● 학생 사진 자동 분류기 (Student Photo Sorter)
> **Nothing Design System 기반 온디바이스 얼굴인식 데스크톱 웹앱**  
> **라이트 모드 기본 / 강원교육모두 Bold 타이포그래피 / 100% 오프라인 보안**

학교 및 교육 현장에서 하루 수백 장씩 쏟아지는 활동·수업·소풍 사진을 **학생별로 100% 로컬 PC에서 안전하고 빠르게 자동 분류**하는 실무 전용 도구입니다.

---

## 🚀 검은색 CMD 콘솔 창 없이 실행하는 방법

1. **바탕화면 바로가기 아이콘 (가장 추천 ⭐️)**
   - 바탕화면에 생성된 **`학생 사진 자동 분류기`** 바로가기를 더블 클릭하시면 검은색 cmd 창이 일체 뜨지 않고 세련된 GUI 창만 즉시 열립니다.
2. **폴더 내 VBS 실행기**:
   - [`학생사진자동분류기.vbs`](file:///C:/Users/goodt/student-photo-sorter/학생사진자동분류기.vbs) 더블 클릭 (CMD 창 0초도 안 뜨는 완전 무음 실행)
3. **폴더 내 배치 파일**:
   - [`run.bat`](file:///C:/Users/goodt/student-photo-sorter/run.bat) 더블 클릭 (백그라운드 실행 후 CMD 창 즉시 자동 종료)

## ✦ 디자인 & 시스템 특징

1. **라이트 모드 기본 (Clean Laboratory Aesthetic)**
   - 화이트 및 슬레이트 캔버스 기반의 고대비 미니멀리즘 인스트루먼트 디자인
   - 직관적인 다크 모드 토글(`☾` / `☼`) 제공

2. **통계 카드 색띠 완전 배제**
   - KPI 통계 카드 좌측의 컬러 바를 제거하여 군더더기 없는 미니멀리즘 계측기 디자인 구현

3. **강원교육모두 Bold 타이포그래피 로컬 번들링**
   - 시스템에 설치된 `강원교육모두 Bold` 폰트 파일을 프로젝트 로컬(`fonts/`)에 직접 번들링하여 외부 CDN 지연 및 폰트 로딩 대기시간(0초)을 완전히 제거했습니다.
   - Windows 고해상도(HiDPI)에서도 텍스트가 뭉개지지 않는 **기본 18px+ 초대형 스케일 / 엄격한 15px 하한선** 준수

4. **비차단(Non-blocking) 비동기 폴링 아키텍처**
   - WebView2 이벤트 루프 교착 상태(Deadlock)를 유발하던 동기 호출 패턴을 완전히 배제하고, 초당 8~10회의 경량 상태 폴링 구조로 전환하여 **실행 시 버벅임 및 무한 대기 현상을 원천 차단**했습니다.
   - Windows 폴더 선택 다이얼로그 또한 독립 프로세스로 분리 실행되어 메인 창 프리즈를 방지합니다.

5. **고대비 조작계 및 드래그 앤 드롭 지원**
   - 윈도우 탐색기에서 폴더를 창으로 직접 끌어다 놓아(Drag & Drop) 간편하게 지정
   - 24px 크기의 솔리드 다크 필 + 고선명 V자 체크박스

6. **실시간 계측 및 결과 요약 갤러리**
   - 실시간 처리 속도(장/초) 및 소요 시간 계측
   - 분류 완료 시 학생별 분류 결과 카드 및 원클릭 '폴더 열기' 바로가기 지원

## 🛡️ 로직 완성도 및 보안 강화

1. **스마트폰 촬영 사진 EXIF 회전각 자동 보정 (`ImageOps.exif_transpose`)**
   - 스마트폰으로 세로 또는 회전 촬영된 사진의 EXIF 방향 메타데이터를 자동 보정하여 정면 얼굴 인식률을 극대화했습니다.

2. **경로 순회(Path Traversal) 공격 원천 차단 (`safe_join`)**
   - 상대 경로(`..`)나 비정상적인 경로 접근을 차단하여 허가된 작업 디렉터리 외부의 파일 수정을 완벽 방지했습니다.

3. **파일명 살균 및 파일 덮어쓰기 방지 (`get_unique_destination_path`)**
   - 대상 폴더에 동일한 파일명이 이미 존재할 경우 `_1`, `_2` 등 고유 번호를 자동 부여하여 원본 사진 덮어쓰기/유실을 방지합니다.

4. **100% 오프라인 온디바이스 프라이버시 보장**
   - 외부 클라우드나 외부 AI API로 사진을 일체 전송하지 않으며, 로컬 PC의 OpenCV ONNX 모델만으로 연산하여 학생들의 개인정보를 철저히 보호합니다.
